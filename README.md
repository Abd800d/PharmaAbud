## تجربة فورية دون تثبيت (نسخة الويب PWA)
افتح `webapp/index.html` بأي خادم ثابت (أو GitHub Pages) — نفس البيانات والمزايا:
بحث ضبابي، أجهزة، تفاصيل، بدائل، إضافة، استيراد/تصدير، مساعد ذكي، رسائل،
بحث بصورة (Lens)، جلب openFDA، ووضع إدارة PIN=1234. تُثبّت على الهاتف كتطبيق (PWA).

## بناء APK للأندرويد
### تلقائياً (موصى به)
ادفع الكود إلى GitHub → تبويب **Actions** → بعد نجاح البناء حمّل
`AbdulmajeedPharma-APH-release-apk` من Artifacts → ثبّت `app-release.apk`.

### محلياً
```bash
flutter create --platforms=android --project-name pharma_encyclopedia --org com.abdulmajeedpharma /tmp/aph_gen
cp -r /tmp/aph_gen/android android && python3 tools/patch_android.py
flutter pub get
flutter build apk --release   # build/app/outputs/flutter-apk/app-release.apk
```

## تنبيهات مهنية مهمة
- لا توجد قاعدة «مليون دواء عالمي موثّقة» مجانية وقانونية جاهزة؛ المعتمد هنا:
  قاعدة بداية حقيقية + استيراد ملفاتك الضخمة + نشر رسمي FDA. هكذا تُبنى القواعد المهنية.
- حقول «وكيل اليمن» مبدئياً تحتاج توثيقك كصيدلي يمني (علّمها ✅ بعد التأكد) —
  البيانات والصور كلها قابلة للتعديل من وضع الإدارة.
- المعلومات تعليمية ولا تغني عن الطبيب/الصيدلي، والأدوية المقيدة بوصفة فقط.
